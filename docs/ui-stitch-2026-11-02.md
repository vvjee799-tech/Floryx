# Floryx · 简序界面整改（2026-11-02）

按已选方案 2「简序·紧凑」与 Google Stitch 精修稿改造现有 Android 界面。本文保留当时实施记录；2026-11-03 已按用户后续选择恢复花开动画和标语，首页与侧边栏标题改为青白粉斜向渐变，并调整新建会话线条图标，最终行为见[启动页说明](bloom-splash-2026-10-27.md)和[1.5.22 发布记录](release-1.5.22.md)。

设计项目：https://stitch.withgoogle.com/projects/5506190101048986589

## 实施

- 暖纸色背景、橄榄色动作、绿色品牌；正文 15sp/24sp、页面标题 20sp/28sp、24dp 内容边距、56dp 设置行。
- 启动页使用现有绿色 f 标志与 Floryx 字标；删除标语。
- 聊天采用淡色用户消息、直接排版的助手内容、圆形发送/停止按钮；模型切换使用可滚动的底部面板，保留模型发现、失败重试与原始服务商资源。
- 设置去掉重复组标题、个人资料说明、版本页脚；会话设置保留头像、提示词和输出上限；外观与语言合并为页面。
- 手机操作、系统助手、答题模式、记忆、命令环境与工作区改为紧凑行布局。保留连接修复、权限入口、命令发送告知、错误和不可撤销操作确认。
- 命令记录单行展示命令、状态、耗时、停止；点击行展开输出。
- 工作区路径、默认开关、待保存文件与保存操作保持真实回调。
- 悬浮面板按屏宽适配，系统助手去掉蓝色与冗余状态说明，截图答案使用暖黑底提升可读性。
- 复用已有图标与品牌资源，未引入新依赖、账户能力或模型请求。

## 验证

- `:app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug` 通过。
- 554 个单元测试：0 失败、0 错误、1 跳过。
- MuMu **Floryx**（核对名称后索引 1，ADB `127.0.0.1:16416`）上 7 项回归通过：设置导航和状态回调、会话编辑与保存确认、模型选择与发送、记忆/工作区/命令/服务商页面、浮窗输入/停止/收起、系统助手后台运行/停止、页面文字默认不附带。
- 截图来自真实 Compose 控件与合成数据，不调用付费模型。390×884dp 的设计比较截图为 780×1768px，排除系统栏。
- 自动化结束后恢复测试前的无障碍启用列表。该新实例原先未启用 Floryx 无障碍服务，因此恢复为未启用；没有留下崩溃服务。
- 原 `FloatingOutputDiagnosticTest` 的渲染夹具会被运行时发布的空会话状态覆盖；旧实例还存在分辨率覆盖后的输入坐标变换。这项旧的整窗穿透诊断没有计入通过的 7 项，日志和基线结果保存在 `build/stitch-ui-qa/`，未宣称其通过。生产触摸逻辑保持当前工作区原有实现。

## 设计适配

本轮沿用原生 Android 返回栏、表单标签、无数据与权限状态；完整服务商目录仍然可滚动。文件待保存卡片显示实际目标文件夹，不伪造文件大小。示例状态与设计稿中的开关值不强制一致。

界面截图画廊：`build/stitch-ui-qa/index.html`。

视觉检查：项目根目录 `design-qa.md`。
