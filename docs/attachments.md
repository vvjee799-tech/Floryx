# 图片与文档附件

点击输入框左侧「＋」按钮可附加图片或文档，支持仅发附件或搭配文字说明一起发送；发送前支持缩略图预览、移除或替换。

## 图片处理与视觉传输

- **解码与规范化**：支持 JPG、PNG、WebP（以及视系统能力支持的其他图片格式，GIF 取首帧）；按 EXIF 方向自动校正，最长边缩至 2048 像素以内，清除原始 EXIF 元数据后保存为不超过 2 MiB 的 PNG 或 JPEG（透明 PNG 在大小允许时保留透明通道）。
- **本地存储与清理**：原始选择文件大小上限为 20 MiB；处理后的附件存储在应用私有目录，数据库仅记录路径和类型。最近 5 轮用户消息中的图片会随追问继续传给支持视觉的模型；删除会话时同步清理关联图片。
- **多协议直传**：图片直接编码为视觉消息块传给当前模型（适配 OpenAI Chat Completions、OpenAI Responses、Anthropic Claude Messages 与 Google Gemini 原生格式），不会在后台擅自切换用户选择的模型。

## 文档解析与长文本分页

- **支持格式**：TXT、Markdown、CSV、JSON、文字型 PDF、DOCX、XLSX、PPTX 与 OpenDocument（ODT / ODS / ODP）。扫描版纯图片 PDF 不内置 OCR，可通过截图/图片视觉方式交由多模态模型识别。
- **有界提取与分页读取**：文档提取保留完整结构（例如修复 XLSX 空列位置对齐），单文档最大提取 80,000 字符；首轮请求向模型注入前 6,000 字符预览，模型可通过只读工具 `read_attachment` 分页按需读取其余已提取正文，避免单个长文档挤占对话预算。
- **隐私边界**：附件正文仅用于当前会话理解，不会作为跨会话长期记忆提取的输入来源。
