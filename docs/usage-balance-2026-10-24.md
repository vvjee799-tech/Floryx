# 用量与余额（1.5.11）

用户要求取消费用估算，经确认改为实际 Token 用量与 DeepSeek 官方账户余额。开关名称调整为“显示用量与余额”，保留原开关状态。

## 数据来源和刷新

- Token：使用模型接口返回的输入、输出、缓存字段，继续按会话保存。不推算未返回的用量。
- 余额：GET https://api.deepseek.com/user/balance，直接显示 total_balance、granted_balance、topped_up_balance 和返回币种，保留十进制精度。
- 开启统计、进入当前服务商会话、回复结束和后台记忆提取返回用量后查询；明细支持手动刷新。
- 回复运行时显示“回复后刷新余额”；查询中不显示旧金额；失败、未配置密钥、非官方接口分别明确提示。查询独立于模型答复，不阻塞发送。
- 不从余额差额推断会话费用。余额是显示更新时间点的账户快照，并非本会话的消费金额，也不承诺逐秒结算。
- 仅允许 HTTPS 的 api.deepseek.com 官方地址及兼容路径。第三方服务商即使模型名称包含 DeepSeek，也不会将其密钥转发到官方余额接口。

[官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)；[模型用量接口](https://api-docs.deepseek.com/api/create-chat-completion/)。
