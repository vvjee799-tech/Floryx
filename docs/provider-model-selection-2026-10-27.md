# 会话中可选模型

日期：2026-10-27。开发源码功能，已在 MuMu 验证并安装到开发版。

## 使用

进入「设置 → 模型与服务商 → 会话中可选模型」，点对应服务商的「选择模型」。

- 获取该服务商的模型列表，勾选需要出现在聊天菜单中的型号。
- 支持搜索、全选、清空、刷新与手动输入模型名称；获取列表失败时仍可手动添加。
- 至少选择一个型号才能保存。取消勾选原默认型号时，界面提示保存后使用的默认型号。
- 保存后聊天切换菜单只显示勾选项；当前旧会话可以继续使用其原型号，菜单不会因此重新加入未勾选项。
- 未配置过选择的服务商沿用原有自动列表。更换已配置预设的 Key 会保留模型选择。

## 保存与同步

- `ProviderConfig.conversationModels` 保存独立于会话的服务商模型选择。`null` 表示沿用自动发现；显式列表表示由用户选择。
- Room 升级到版本 15，迁移只增加可空的 `providers.conversationModelsJson` 列。旧配置、已有密钥与消息继续保留。
- 自定义型号、默认型号更新、取消编辑、配置刷新与异步列表回包均有相应处理。
- 已配置显式选择的 Gemini 服务商在聊天打开菜单时不再自动请求完整列表。
