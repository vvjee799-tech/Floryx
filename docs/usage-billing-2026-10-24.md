# 用量与费用：实现与验证（2026-10-24）

版本：Floryx Dev 1.5.10（24），数据库版本 12。

此文记录 1.5.10 的历史实现。1.5.11 已按用户要求移除估算费用，改为官方账户余额，详见 [用量与余额](usage-balance-2026-10-24.md)。

## 使用方式

设置 → 用量与费用 → 显示用量与费用，默认关闭。开启后，输入框下方、模型选择左侧显示本会话累计 Token 和人民币估算费用。点击可查看输入、输出、缓存命中、已返回用量的请求比例及计价说明。

仅累计开启期间发起、带有本会话归属的 DeepSeek Chat Completions 请求，包含普通对话、工具续答、上下文整理和记忆提取。关闭后隐藏显示、停止新请求统计，保留已有数据；已开始的请求仍可补齐用量。历史请求无法补算。删除会话时对应记录一并删除。

## 统计与价格

每个 HTTP 请求生成独立本地 ID，重复用量事件更新同一记录。非流式回退作为另一次请求记录。未返回用量的请求保留未知状态，不能推断为零消耗；缺少缓存字段时扩大估算区间。价格未知的模型只记录 Token，不计入已知费用。

费用以整数纳元保存，累计后展示，避免小额逐条舍入误差。记录保存请求当时的模型、价格版本和费用，不随当前模型切换重新计算。此功能不查询账户余额，也不控制服务商扣费。

价格来源：[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核实日期 2026-10-24。人民币/百万 Token：

| 模型 | 缓存命中输入 | 未命中输入 | 输出 |
| --- | --- | --- | --- |
| deepseek-flash / deepseek-v4-flash / deepseek-v4-flash-vision-exp | 0.02–0.04 | 1–2 | 4–8 |
| deepseek-v4-pro | 0.15–0.30 | 4.5–9 | 13.5–27 |

区间覆盖空闲／高峰费率，不自行推断节假日或服务商结算时点。第三方服务商可能使用不同价格，实际费用以其账单为准。deepseek-chat、deepseek-reasoner 等未在当前价格表明确列出的名称不猜测映射。

## 过程中发现并处理的问题

- 原网络客户端在 finish_reason 后立即停止读取，会遗漏兼容接口随后返回的 usage-only 事件。开启统计时增加最多 1.5 秒的尾部读取窗口；不影响未开启统计时的行为。
- 原数据库源码契约测试固定版本 11，升级后同步更新为 12；实际迁移测试通过。
- 新 HTTP 模拟测试最初缺少 HttpTimeout 插件，补齐与生产客户端一致的测试配置。回退测试最初两次都返回含用量 JSON，修正为第一次空流、第二次完整 JSON，以准确验证未知首次请求的情况。
- 初次界面截图早于画面提交，已增加 UI 空闲等待并重新检查，最终截图正确包含弹窗。
