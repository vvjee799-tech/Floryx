# Provider icon attribution

The Qwen, GLM (Zhipu), Kimi, Grok, MiniMax and Doubao icons are from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons). Source SVGs: `qwen-color.svg`, `zhipu-color.svg`, `kimi-color.svg`, `grok.svg`, `minimax-color.svg`, `doubao-color.svg`
