# Floryx 1.5.22 · 正式发布与验证

发布日期：2026-11-03。本版包含此前 1.5.21 测试阶段与当前工作区的全部功能改动。完整更新记录见 [CHANGELOG](../CHANGELOG.md)。

## 主要变化

- 花开启动动画标准时长延长到 1.5 秒，花瓣平滑、缓慢展开；去掉前置静态图标，减少逐帧重组，并在播放期间请求设备支持的最高刷新率。实际帧率仍受屏幕与系统限制。
- 首页与侧边栏的 Floryx 标题统一为左上到右下的青、白、粉渐变。新建会话图标采用更圆润、较粗的线条与向右上移出的笔，显示尺寸为原来的五分之四。
- 聊天、模型选择、设置和浮窗采用统一紧凑布局，保留发送、停止、保存及返回确认。
- 答题模式支持长按悬浮球截图、顶部暖黑底卡片实时显示答案、点击查看所属会话和关闭输出；截图期间隐藏浮层，拒绝安全窗口，不覆盖已有草稿。
- 任务可在聊天页面关闭后继续运行，支持通知停止、中断记录与恢复时不重放。Root 服务按需连接，新增默认关闭的后台执行屏实验功能。
- 新增系统助手面板与快捷设置入口，页面文字默认不附带；第三方 DeepSeek 已知 V4/V4.1 型号使用百万上下文本地预算策略，服务商实际限额仍以接口为准。

## 安装与兼容

- 显示名 **Floryx**，版本 **1.5.22（36）**，Android 8.0 / API 26 及以上，ARM64-v8a 与 x86_64。
- 历史兼容包名 `com.flowchat.app.debug`，采用关闭调试的 Release + R8 构建，沿用既有签名；包名后缀不代表本附件是调试包。
- 直接覆盖安装以保留配置、密钥和会话。不要先卸载旧版。本版数据库为 16，包含 15→16 的任务记录迁移；未验证向旧版本降级。
- 后台执行屏需要 Android 15+、Root、Power 模式与无障碍等条件，默认关闭。系统助手、后台保活和权限行为会受设备系统限制。

## 构建与验证

- 全量 Debug 单元测试 556 项：555 通过、1 项 Windows 环境用例跳过，零失败或错误。跳过项为 `SafeTarExtractorTest.rejectsLinkTraversalThroughAnEarlierDirectoryAlias`。
- Release lint 零错误、217 条警告和 1 条信息；警告主要涉及未使用资源、依赖版本与声明方式，也包括第三方 `bcpkix-jdk15to18:1.72` 的 TLS 信任管理器提示。这些提示仍需后续依赖升级及调用链审查。
- Release/R8 构建、版本、显示名、包名、非调试标志与签名核验通过。首次并行打包因主机内存不足退出，改为单 worker 并分开运行验证与 R8 后成功；失败日志不计入通过结果。
- Floryx MuMu（Android 15）共 20 项设备检查通过，覆盖花开动画、主题与布局、刷新率提示恢复、设置和浮窗、官方/第三方 DeepSeek 本地模型链路、系统助手、后台任务以及答题模式。关闭系统动画的用例单独执行通过；答题用例同步当前设置子页、暖黑底答案卡与截图时输入窗口变化后复测通过，早期失败保留在本地日志。
- 同一正式 APK 在 Floryx MuMu 保留数据覆盖安装成功，UID、数据目录和首次安装时间保持一致。回读已安装 APK 的 SHA-256 与附件一致，冷启动 `Status: ok`，首帧 197 ms；该耗时不代表完整花开动画或首页准备时长。首页渐变标题和新建会话图标正常显示，未发现本次冷启动应用崩溃。
- 测试后已恢复原动画倍率 0.5 与原无障碍服务列表，并确认 Floryx 服务实际绑定且不在故障列表中。本轮未测量高刷实体屏上的实际帧率。
- 本轮未向真实模型发送测试请求，未重新执行实体手机、长期 Doze/耗电或 Root 副屏硬件验证。既有手机记录见[整体验收](phone-integration-verification-2026-10-29.md)；不能据此推断所有厂商系统均已通过。
