# Floryx 1.5.19

独立设置页面、会话管理与模型适配更新，项目和 GitHub 仓库统一使用 **Floryx**。

- **独立设置页面**：设置、会话设置及记忆、手机操作、命令环境、工作区使用固定顶栏与左上角返回，内容在页面内滚动。
- **资料分别编辑**：侧边栏头像和名字仅展示；设置中点击头像或角落铅笔更换头像，单击名字修改。会话设置按助手资料、对话规则、回复设置分组，提示词单独编辑，返回时可保存或放弃草稿。
- **聊天阅读与管理**：回看历史时保护阅读位置，支持回到最新、历史按需加载、Markdown 回复及代码复制；会话可置顶、归档恢复或导出。
- **服务商与模型**：各服务商可分别选择聊天中显示的模型；Gemini 官方连接采用原生接口，支持思考摘要、工具续轮及图片，兼容已有配置和密钥。
- **手机操作响应**：页面等待采用事件唤醒与有限轮询，优化局部像素比较和滑动后的画面检查。
- **名称统一**：仓库链接、设计规范与后续发布资料使用 Floryx。旧安装身份与持久化标识保留，具体范围见[更名记录](https://github.com/vvjee799-tech/Floryx/blob/v1.5.19/docs/project-rename-2026-10-27.md)。

## 已知限制

MuMu 电脑输入模式未显示可核验的软键盘框，软键盘遮挡检查仍有限。既有横屏主界面手机接管卡片按钮可能被底部输入区挤出的情况不在本次设置页优化范围内，见[已有记录](https://github.com/vvjee799-tech/Floryx/blob/v1.5.19/docs/floating-confirmation-2026-10-26.md)。
