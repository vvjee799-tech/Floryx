# 摘要式记忆

「设置 → **记忆**」开关控制跨会话长期记忆的读取与自动提取。关闭开关后，应用停止读取与新增记忆，已保存的记忆条目仍可在管理页查看、编辑、单条删除或一键清空。

## 记录边界与隐私保护

- **仅提取长期有效信息**：对话成功完成后，系统筛选稳定偏好（如回复语言与风格偏好）、用户明确提及的个人事实与持续推进的项目背景，整理为结构化短摘要；普通日常问答、临时设备操作、报错信息与附件正文不会写入记忆。
- **自动脱敏跳过**：包含密钥、密码或敏感凭据的输入自动跳过记忆提取。
- **提取机制与配额**：摘要使用当前配置的模型发出独立短请求（禁用工具与思考、超时 20 秒），单次最多新增 3 条、每条上限 180 字、本机总量上限 80 条；同一主题自动按键值更新而非无限叠加重复条目。

## 管理与可控性

- 管理界面按「关于你 / 使用偏好 / 持续项目」分类展示所有记忆，支持随时编辑修正或删除。
- 关闭记忆开关、手动修改、删除或清空记忆时，所有正在进行的后台异步提取都会自动失效，确保已删除的内容不会被迟到的后台任务重新写回。
