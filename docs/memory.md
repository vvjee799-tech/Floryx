# 摘要式记忆

设置页的“记住有用的信息”开关同时控制记忆的读取和新增。关闭后，已保存的摘要仍可查看、编辑、单条删除或清空；聊天记录与记忆分别管理。

记忆参考 [ChatGPT 官方个性化说明](https://learn.chatgpt.com/docs/personalize) 中保留稳定偏好、重复工作方式和长期背景的思路。

## 保存什么

- 稳定偏好，例如默认回复语言和表达风格。
- 用户明确说明的个人事实，例如昵称。
- 持续进行的项目背景。

普通问答、问候、临时设备操作、助手输出和任务错误不会直接保存。含有凭据或敏感信息的输入会跳过自动提取。附件正文不会作为记忆提取输入。

成功完成回复后，符合条件的用户原文会交给当前服务商和模型整理成结构化摘要。这是独立的短请求，可能增加少量模型用量，界面中有说明；无需配置第二个服务商。摘要请求不启用工具，不请求额外思考，最多等待 20 秒。失败、未完成或格式不合法时不新增记忆，不退回保存原始问答。

每次最多保存三条，每条最多 180 字。同一主题复用键值并更新原有摘要，避免不断追加重复信息。本机最多保留 80 条，优先检索与问题相关的摘要；长期个人偏好可跨话题使用。

## 更新与控制

管理页可修改摘要，并按偏好、个人事实、持续项目显示。关闭开关、手动编辑、删除或清空会使尚未完成的自动提取失效，防止后台结果重新写回已经移除的内容。

升级时，旧版每轮问答的副本会在本机进行一次筛选：仅保留原始用户语句中明确的长期信息，并去除助手回复和临时操作副本。原始聊天记录不受此过程影响。

模型可能遗漏或误判信息，管理页可随时修正。测试使用模拟模型流与隔离的界面数据，不需要真实密钥或付费请求。
