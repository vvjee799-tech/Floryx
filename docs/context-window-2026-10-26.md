# 输入框上下文占用圆环

在输入框下方的思考选项右侧增加 16dp 灰色圆环，保留 48dp 点击区域。点击圆环在上方显示黑色圆角详情浮层：上下文窗口、估算已用百分比、已用标记和总预算。支持返回键及点击浮层外部关闭，切换会话时关闭旧浮层；浅色、深色和较大字体沿用同一交互。

显示的是当前请求窗口的估算占用，包括请求指引、工具定义、历史投影、已提交的任务检查点、当前消息和运行中的回复；不是会话累计消耗。总量来自 `TaskContextManager` 的会话硬预算，目前默认 32,000 标记，不代表服务商模型的标称上下文容量。界面注明估算和会话预算口径；超预算时百分比可超过 100%，圆环最多填满一圈。

空闲时对草稿和附件做延迟估算，不读取图片字节；通过共享请求构造与服务商序列化规则计算，图片按既有预算计入。运行时使用实际任务请求，随回复和工具返回更新，整理提交后按新窗口重算。空闲时的记忆部分使用已载入的记录估算，实际发送时以检索结果为准。

为显示圆环读取检查点时只恢复有效窗口，不请求摘要、不保存检查点，也不增加模型调用。未获得有效估算时明确显示「尚无上下文估算」。每个运行实例有独立快照；流式刷新合并到约 150ms，强制更新、停止及任务结束会取消旧刷新，避免旧任务覆盖新任务。
